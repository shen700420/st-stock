🔑 GitHub Token 設定

需要一組 GitHub Fine-Grained PAT，讓「刷新」按鈕能觸發 Actions 自動抓取最新股價。
Token 只存在您的瀏覽器 localStorage，不會上傳至任何伺服器。

📖 如何產生 Token（點擊展開）
  1. 前往 GitHub → Settings → Developer settings → Fine-grained tokens
  2. 點 Generate new token，名稱隨意（例如 st-dashboard）
  3. Repository access 選 Only select repositories → 選 st-stock
  4. Permissions → Actions 設為 Read and write
  5. 產生後複製貼上到下方欄位
